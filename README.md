# INDUSTRIAL CREATOR — Инструкция по запуску в VS Code

Этот проект создан на **React + TypeScript + Vite + Tailwind CSS**.

## Почему сайт не открывается, если просто дважды кликнуть на `index.html`?
Современные приложения на React и TypeScript состоят из файлов `.tsx` и модулей. Обычный браузер напрямую из папки («двойным кликом») не умеет запускать `.tsx` файлы — ему нужен быстрый локальный сервер разработки (**Vite**), который компилирует код и сразу показывает готовый сайт.

---

## 🚀 Самый быстрый способ запуска (2 шага):

### Вариант 1: В 1 клик через готовые файлы
* **На Windows**: просто дважды кликните по файлу **`start-windows.bat`**.
* **На Mac / Linux**: запустите файл **`start-mac.sh`**.
*(Скрипт сам проверит Node.js, установит нужные файлы и откроет сайт в браузере)*.

---

### Вариант 2: Запуск прямо внутри Visual Studio Code (пошагово)

1. Убедитесь, что на компьютере установлен **Node.js** (скачать бесплатно с официального сайта: [nodejs.org](https://nodejs.org), версия LTS).
2. Распакуйте скачанный архив с сайтом в любую папку на компьютере.
3. Откройте **Visual Studio Code**, выберите меню:
   * **Файл (File) -> Открыть папку (Open Folder...)** и выберите папку с этим проектом.
4. Откройте встроенный терминал в VS Code:
   * Нажмите комбинацию клавиш: **`Ctrl + ~`** (или **`Ctrl + \``**, на клавиатуре буква «Ё»)  
   * Либо в верхнем меню VS Code: **Терминал (Terminal) -> Новый терминал (New Terminal)**.
5. В открывшемся внизу терминале введите команду установки модулей (делается 1 раз при первом запуске):
   ```bash
   npm install
   ```
   *Нажмите Enter и подождите 10-20 секунд, пока загрузятся библиотеки.*
6. Теперь запустите сайт командой:
   ```bash
   npm run dev
   ```
7. В терминале появится строка:
   ```text
   VITE ready in 250 ms

   ➜  Local:   http://localhost:3000/
   ➜  Network: use --host to expose
   ```
8. Зажмите клавишу **Ctrl** (или **Cmd** на Mac) и **кликните мышкой по ссылке `http://localhost:3000/`**, либо просто скопируйте её и откройте в вашем браузере (Chrome, Yandex, Edge, Safari).
9. Сайт откроется и будет работать в реальном времени! Если вы будете менять любой текст или код в VS Code, страница в браузере будет мгновенно обновляться без перезагрузки.

---

## 🛠 Полезные команды в терминале:
* `npm run dev` — запустить локальный сервер для просмотра и редактирования сайта.
* `npm run build` — собрать готовую статическую версию для публикации на хостинг в папку `dist/`.
* `Ctrl + C` (в терминале) — остановить сервер.
